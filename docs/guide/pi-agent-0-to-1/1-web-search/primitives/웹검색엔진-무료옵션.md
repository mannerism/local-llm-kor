# 웹 검색엔진: 무료 옵션

## 이게 뭐예요?
**API 키도, 신용카드도 없이 공짜로 [[pi]]한테 검색을 붙이는 검색엔진들이에요.** 이 페이지도 [[웹검색-원리]]의 **1단계(목록 받아오기)**를 맡는 검색엔진 모음입니다. 상용 서비스([[웹검색엔진-유료옵션]])가 깔끔하긴 한데, 돈이 들고 내 검색어가 남의 서버로 나갑니다. 이 페이지는 **공짜로, 그리고 가능하면 내 컴퓨터 안에서** 끝내는 옵션을 모았어요. 로컬 LLM을 굴리는 우리 시리즈 취지와 제일 잘 맞는 쪽입니다.

솔직하게 먼저 짚을게요. **진짜로 무제한 공짜인 "범용" 웹 검색은 사실상 두 길뿐이에요.**

1. 검색엔진을 내 컴퓨터에 직접 띄우거나 (self-host, 자체 호스팅)
2. 비공식 방법으로 긁어오거나 (스크래핑)

진짜 검색 인덱스를 굴리는 건 돈이 많이 들어요. 그래서 그 외의 "무료"는 대부분 **횟수 제한(맛보기)**이 있거나 **검색 범위가 좁습니다**(예: 위키백과만). 이 점만 알고 고르면 실망할 일이 없어요.

## 진짜 공짜 + 범용: 자체 호스팅이 정답
무제한으로 마음껏, 그리고 검색어도 안 새는 범용 검색을 원하면 결국 **내가 직접 띄우는** 방식이에요. 손이 좀 가지만 한 번 해두면 계속 공짜입니다.

### SearXNG: 가장 '로컬다운' 선택
**강점**
- 내 컴퓨터(또는 집 서버)에 직접 띄우는 **메타 검색엔진**이에요. 구글, 브레이브, DuckDuckGo 등 여러 곳을 한 번에 뒤져서 결과를 합쳐 줍니다.
- API 키가 없고 완전 무료예요. 검색어가 밖으로 새지 않습니다 (프라이버시 최고).
- 결과를 JSON으로 받아서 Pi에 바로 연결할 수 있어요.
- **모델도 로컬, 검색도 로컬**이라 이 시리즈 철학과 딱 맞아요.
- 설치가 부담되면, 남이 띄워 둔 **공개 인스턴스**(searx.space 목록)에 그냥 질의만 할 수도 있어요. 다만 남의 서버라 느리거나 막힐 수 있으니 연습용으로만 쓰세요.

**약점**
- 직접 설치하고 실행해야 해요 (Docker로 한 번 띄우는 수고).
- 너무 자주 쓰면 뒤에 있는 검색엔진 쪽에서 일시적으로 막을 수 있어요.

🔗 https://github.com/searxng/searxng · 문서 https://docs.searxng.org · 공개 인스턴스 목록 https://searx.space

### YaCy: 완전 분산형, 더 독립적
**강점**
- 오픈소스 **P2P(피어 투 피어, 참여자끼리 직접 나눔)** 검색엔진이에요. 각자 크롤링한 걸 나눠 갖는 구조라 특정 회사에 안 매여요.
- 완전 무료, 자체 호스팅, 프라이버시도 좋아요.

**약점**
- 인덱스가 참여자 기여에 의존해서 **결과가 들쭉날쭉**해요. 구글만큼 촘촘하진 않습니다.
- 설치하고 운영하는 게 SearXNG보다 좀 무거운 편이에요.

🔗 https://yacy.net (SearXNG부터 써 보고, 더 독립적인 걸 원할 때 YaCy로 가면 됩니다.)

### DuckDuckGo: 설치 거의 없이 빠르게
**강점**
- `ddgs` 같은 라이브러리로 **키 없이 바로** 검색해요.
- 가볍고 빠릅니다. 맛보기나 프로토타입에 딱이에요.

**약점**
- 공식 API가 아니라 **언제든 막히거나 깨질 수 있어요** (안정성 낮음).
- 요청을 많이 하면 rate limit(횟수 제한)에 걸립니다.

🔗 https://github.com/deedy5/ddgs

## 완전 공짜지만 범위가 좁아요
범용은 아니지만, 용도만 맞으면 아주 쓸모 있어요. 키도 필요 없습니다.

### Wikipedia / MediaWiki API: 사실 확인엔 최고
**강점**
- 위키백과 공식 API예요. 키 없이 완전 무료고 안정적입니다.
- 인물, 역사, 개념 같은 **백과사전식 사실 확인**엔 일반 검색엔진보다 깔끔해요.

**약점**
- 위키백과 안에서만 찾아요. 최신 뉴스, 쇼핑, 일반 웹은 못 합니다.

🔗 https://www.mediawiki.org/wiki/API:Search

### Marginalia: 인디·글 위주 독립 검색
**강점**
- 광고와 SEO 떡칠 페이지를 걷어내고 **글과 문서 위주**로 보여주는 독립 검색엔진이에요. 비상업 용도 무료 API를 제공합니다.
- 깊이 있는 글, 옛 웹, 기술 문서를 찾을 때 의외로 좋아요.

**약점**
- 인덱스가 작아요. 최신 뉴스, 상품, 실시간 정보엔 안 맞습니다.

🔗 https://marginalia-search.com
