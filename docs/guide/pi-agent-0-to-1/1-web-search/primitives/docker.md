# Docker

![[Xnip2026-06-02_15-36-09.png]]
## 이게 뭐예요?
**프로그램을 "컨테이너(container)"라는 격리된 공간에서 돌리는 도구예요.** 컨테이너 안에는 그 프로그램과, 프로그램이 돌아가는 데 필요한 라이브러리·설정이 함께 들어 있어요. 그래서 내 컴퓨터에 뭐가 깔려 있든 상관없이, 컨테이너 안에서는 늘 똑같은 환경으로 돌아갑니다.

아파트로 비유하면 정확해요. 컨테이너는 한 건물 안의 **독립된 방**이에요. 방마다 문이 잠겨 서로 간섭하지 않지만(격리), 건물의 **기초와 배관, 즉 내 컴퓨터의 핵심 엔진은 같이 씁니다(공유).**

이게 **가상머신(VM)과 다른 점**이에요. 가상머신은 프로그램마다 건물을 통째로 새로 짓는 격이라 무겁고 느려요. 컨테이너는 있는 건물에 방만 하나 내주는 거라 **가볍고 몇 초 만에 뜹니다.**

## 왜 이걸 쓰나요?
- **설치가 한 줄로 끝나요.** 복잡한 설치 단계를 상자가 이미 다 품고 있어서, 받아서 실행만 하면 돼요.
- **"내 컴퓨터에선 됐는데" 문제가 없어요.** 누구 컴퓨터든 똑같은 상자라 똑같이 작동해요.
- **깔끔하게 지워져요.** 상자만 버리면 끝. 컴퓨터 여기저기 찌꺼기가 안 남아요.

[[searxng]] 같은 도구를 복잡한 설치 없이 명령어 한 줄로 띄우려고 우리가 Docker를 씁니다.

## Docker 기본 개념
이 네 가지만 알면 Docker를 이해할 수 있습니다. 게임으로 비유해 볼게요.

- **이미지(image)**: 옛날 소프트웨어 **CD 한 장**처럼, 넣으면 그 자체로 돌아가는 **완성품**이에요. 프로그램과 필요한 파일이 전부 안에 담겨 있고, 내용은 안 바뀝니다(읽기 전용). 다운로드 받는 게 이거예요.
- **컨테이너(container)**: 그 CD를 넣고 실제로 구동하는 가상의 CD플레이어 같은 개념이에요. 자기만의 파일과 프로세스를 가져서 **작은 컴퓨터처럼 보이지만**, 핵심 엔진은 내 컴퓨터와 공유하는 점에서 진짜 독립 컴퓨터(가상머신)와는 달라요. 이미지 하나로 컨테이너를 여러 개 띄울 수 있고, 컨테이너 하나는 늘 **이미지 한 장에서** 출발해요.
- **레지스트리(registry, 예: Docker Hub)**: 이미지를 받아오는 **온라인 스토어**예요. 앱스토어에서 앱 받듯 여기서 이미지를 내려받습니다(`pull`).
- **엔진(engine, 데몬)**: 이미지를 읽어 컨테이너로 굴리는 **게임기 본체**예요. 맥에선 **Docker Desktop**을 켜면 이 엔진이 돌아갑니다. (그래서 설치 후 앱을 한 번 실행해야 해요.)

한 줄로 꿰면: **스토어(레지스트리)에서 CD(이미지)를 받아, 게임기(엔진)가 그 CD로 게임(컨테이너)을 돌린다.**

그림으로 보면 이래요.

```
   레지스트리 (Docker Hub)              ← 이미지 보관 스토어
          │
          │  docker pull   (이미지 내려받기)
          ▼
   이미지  (예: searxng/searxng)        ← 완성품 CD, 읽기 전용
          │
          │  docker run    (이미지로 컨테이너 생성)
          ▼
 [ 컨테이너 ]  [ 컨테이너 ]  [ 컨테이너 ]   ← 이미지 1장 → 컨테이너 여러 개
        └──────────┬──────────┘
                   ▼
   Docker 엔진 (Docker Desktop)          ← 컨테이너를 굴리는 본체
                   ▼
   내 컴퓨터 (호스트)                     ← 핵심 엔진을 모두가 공유
```

> 프로그램을 여러 개 돌리고 싶으면? **컨테이너를 여러 개** 띄워요. PostgreSQL·Redis·Nginx도 한 컨테이너에 다 넣는 게 아니라 **각각 따로** 띄워서 연결합니다. 게임기 한 대당 게임 하나인 셈이에요. (컨테이너 하나 = 역할 하나, 이게 정석.)

컨테이너를 띄울 때 자주 붙이는 옵션 둘도 알아두면 좋아요. **포트(`-p`)**는 컨테이너를 바깥과 잇는 통로, **볼륨(`-v`)**은 데이터를 컨테이너 밖에 저장해 두는 장치예요. 둘 다 [[searxng-설치]]에서 실제로 씁니다.
