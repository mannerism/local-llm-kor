# Jina Reader 설치 (내 맥북에서 돌리기)

> [[jina-reader]]가 뭔지, 왜 골랐는지는 앞 글에서 다뤘어요. 여기선 self-host로 띄우는 법만 봅니다. [[searxng-설치]]에서 Docker를 이미 깔았으면 바로 이어가요.

[[searxng]]와 똑같이 **Docker**로 띄워요. 다만 Jina Reader는 **설정 파일도 필요 없어요.** 컨테이너만 띄우면 바로 작동합니다. (상태를 안 들고 매 요청이 깔끔해요.)

## 1. 띄우기
이미지를 받아서 컨테이너로 띄워요. **아무 폴더에서 실행해도 괜찮아요.** SearXNG와 달리 `-v`(폴더 연결)가 없어서, 폴더를 만들지도 참조하지도 않거든요.

```sh
docker run -d --name jina-reader -p 3000:8081 ghcr.io/jina-ai/reader:oss
```

- `-d`: 백그라운드로 돌려요.
- `--name jina-reader`: 컨테이너 이름이에요.
- `-p 3000:8081`: 내 컴퓨터의 3000 포트로 접속하면 컨테이너 안 Jina Reader(8081, HTTP/1.1)로 연결돼요.

> 이미지에 브라우저(Chromium)가 들어 있어서 **처음 받을 때 용량이 꽤 커요.** 다운로드가 좀 걸려도 정상이에요.

## 2. 잘 됐는지 확인
먼저 컨테이너가 도는지 봐요.

```sh
docker ps --filter name=jina-reader
```

![[Xnip2026-06-02_21-18-14.png]]

이제 아무 주소나 읽혀 봐요. **요청 형식이 독특해요.** `http://localhost:3000/` 뒤에 읽고 싶은 URL을 그대로 붙입니다.

```sh
curl http://localhost:3000/https://example.com
```

`example.com`의 본문이 **마크다운**으로 나오면 성공이에요. 이제 [[pi]]에 붙일 준비가 끝났어요.
