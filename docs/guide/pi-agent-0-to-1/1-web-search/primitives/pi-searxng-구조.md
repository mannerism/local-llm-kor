# Pi와 SearXNG는 어떻게 연결되나요

## 이게 뭐예요?
[[searxng]]는 **검색엔진 역할**이에요. 키워드를 던지면, 브레이브 같은 여러 검색엔진을 대신 뒤져서 **결과 리스트(제목·주소·요약)**를 가져다줍니다.

이걸 [[pi]]와 연동해요. Pi가 검색이 필요할 때 SearXNG한테 키워드를 넘기고, **그 리스트를 받아서** 답에 씁니다.

**첫 단계는 딱 여기까지예요.** 키워드 주고 리스트 받기. 링크에 들어가 본문까지 읽는 건 다음 단계입니다 ([[웹검색-원리]]).

## 둘은 따로 도는 프로그램이에요
Pi와 SearXNG는 **완전히 분리된 별개 프로그램**이에요.

- **Pi**: 모델을 굴리는 쪽
- **SearXNG**: 검색하는 쪽
- 둘 사이는 **HTTP로만** 이어져요

그래서 각자 따로 켜고 끌 수 있고, 검색엔진을 나중에 다른 걸로 바꿔도 Pi는 안 건드려요.

## 큰 그림
```
[ Pi + 모델 ]
     │  키워드로 검색 요청 (HTTP)
     ▼
[ SearXNG ]   ← 검색엔진들을 대신 뒤짐
     │
     ▼
[ 브레이브 · 구글 · DuckDuckGo · ... ]

→ SearXNG가 결과를 모아 리스트로 Pi에 돌려줘요.
```
