# 웹 검색엔진: 유료 옵션

## 이게 뭐예요?
**[[pi]]한테 "인터넷을 검색하는 손"을 달아주는 검색엔진 모음이에요.** 로컬 모델은 자기 머릿속에 있는 지식만 알아요. 최신 정보나 모르는 걸 물으면 지어내거나 "모른다"고 합니다. 여기에 검색엔진을 붙이면, Pi가 직접 인터넷을 뒤져서 자료를 찾아와요.

이 페이지는 [[웹검색-원리]]의 **1단계(목록 받아오기)**를 맡는 검색엔진 중에서 **돈을 내고 쓰는 상용(commercial, 회사가 파는) 서비스**를 모았어요. (본문 읽기 2단계 도구는 별도 primitive에서 다룹니다.) 대부분 API 키(서비스에 접속하는 비밀번호 같은 것) 하나만 받으면 바로 연결돼서 깔끔하고, 결과 품질도 안정적입니다. 공짜로 굴리는 방법은 [[웹검색엔진-무료옵션]]에서 다뤄요.

> 거의 다 **무료 체험 티어(free tier)**가 있어요. 한 달에 몇 백~몇 천 건은 공짜라, 일단 키만 받아서 써 보고 마음에 들면 결제하면 됩니다. 지금 당장 돈 들 걱정은 안 해도 돼요.

## 먼저 읽고 오면 좋아요
웹 검색이 "목록 받기"와 "본문 읽기" 두 단계로 나뉜다는 점, 그리고 도구마다 어디까지 해주는지는 [[웹검색-원리]]에서 설명했어요. 아래 표의 "검색/읽기" 칸이 바로 그 구분입니다.

## 한눈에 보기
| 도구 | 한 줄 설명 | 검색/읽기 | 링크 |
|---|---|---|---|
| Tavily | agent용으로 만든 검색. 결과가 바로 모델용 | 검색 + 읽기 | https://tavily.com |
| Exa | "뜻으로 찾는" 의미 검색. 비슷한 글 발굴에 강함 | 검색 + 읽기 | https://exa.ai |
| Perplexity Sonar | 링크 말고 답과 출처를 만들어 줌 | 답 생성 | https://docs.perplexity.ai |
| Brave Search API | 자체 검색 인덱스. 저렴 | 검색 | https://brave.com/search/api/ |
| Serper.dev | 구글 결과를 JSON으로. 빠르고 쌈 | 검색 | https://serper.dev |

### Tavily: 제일 무난한 출발점
**강점**
- agent용으로 설계돼서, 검색 결과가 군더더기 없이 **모델이 바로 먹기 좋은 형태**로 나와요.
- 한 번 호출로 검색, 본문 추출, 요약까지 옵션으로 처리합니다.
- 무료 티어가 넉넉하고 문서가 친절해요.

**약점**
- 결국 외부 유료 서비스라, 많이 쓰면 과금됩니다.
- 내 검색어가 외부 서버로 나가요 (프라이버시).

🔗 https://tavily.com · 문서 https://docs.tavily.com

### Exa: 키워드 말고 '의미'로 검색
**강점**
- 임베딩(글의 뜻을 숫자로 바꾼 것) 기반이라 "이런 느낌의 글" 같은 **의미 검색**에 강해요.
- 리서치나 비슷한 자료 찾기에 잘 맞아요.
- 본문 가져오는 기능도 내장돼 있어요.

**약점**
- 단순 사실 검색은 일반 검색엔진이 더 직관적일 때도 있어요.
- 유료예요.

🔗 https://exa.ai

### Perplexity Sonar: 검색을 넘어 '답'까지
**강점**
- 링크 목록이 아니라 **출처가 달린 완성된 답**을 돌려줘요.
- Pi가 따로 정리할 필요가 줄어듭니다.

**약점**
- "답을 대신 써주는" 구조라, 내 로컬 모델한테 생각시킬 여지가 줄어들어요. 로컬 LLM을 굴리는 재미와는 살짝 안 맞습니다.
- 종량제(쓴 만큼 과금)예요.

🔗 https://docs.perplexity.ai

### Brave Search API: 독립 인덱스, 가성비
**강점**
- 구글이나 빙을 빌려 쓰는 게 아니라 **자체 인덱스**예요. 그래서 결과가 남들과 다르고 프라이버시를 지향합니다.
- 가격이 싼 편이에요.

**약점**
- agent 친화 가공은 약해요. 링크와 요약만 주므로 본문 읽기는 Pi가 따로 해야 합니다.

🔗 https://brave.com/search/api/

### Serper.dev / SerpAPI: 구글 결과 그대로 JSON
**강점**
- 우리가 익숙한 구글 검색 결과를 그대로 JSON으로 받아요.
- Serper는 빠르고 저렴하며 무료 크레딧이 있어요.

**약점**
- 검색만 합니다. 본문 읽기는 별도예요.
- 형제 격인 SerpAPI(https://serpapi.com)는 더 다양한 검색엔진을 지원하지만 더 비쌉니다.

🔗 https://serper.dev

> ⚠️ **Bing Web Search API는 쓰지 마세요.** 마이크로소프트가 2025년에 종료했어요. 옛날 글이나 튜토리얼에 자주 보이지만 지금은 작동하지 않습니다.
