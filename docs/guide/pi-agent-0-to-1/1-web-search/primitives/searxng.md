# SearXNG


## 이게 뭐예요?![[Xnip2026-06-02_15-28-41.png]]
**여러 검색엔진에 한꺼번에 물어보고, 그 결과를 하나로 합쳐서 돌려주는 "검색 대리"엔진 이에요.** 내가 직접 구글, 브레이브, DuckDuckGo를 일일이 돌아다닐 필요 없이, SearXNG한테 한 번 물으면 뒤에서 여러 곳을 동시에 뒤져서 정리해 줍니다. 이런 걸 **메타 검색엔진(metasearch engine)**이라고 해요.

핵심은 **내 컴퓨터에 직접 띄워서(self-host) 쓴다**는 점이에요. 그래서 검색어가 밖으로 안 새고, API 키도 돈도 안 듭니다. [[웹검색-원리]]의 1단계(목록 받아오기)를 맡는 도구이고, [[웹검색엔진-무료옵션]] 중에서 우리가 고른 주인공입니다.

- 공식 문서: https://docs.searxng.org
- 코드: https://github.com/searxng/searxng
- 라이선스: AGPL-3.0 (오픈소스)
- 공개 인스턴스 목록: https://searx.space

## 강점
- **완전 무료 + API 키 없음**: 횟수 제한이나 과금 걱정이 없어요.
- **프라이버시 최고**: 검색어가 내 기계 밖으로 안 나가고, 추적·프로필링도 안 해요.
- **메타 검색**: 한 곳에 안 매이고 여러 엔진을 합치니, 한 엔진이 막혀도 다른 데서 가져와요.
- **JSON 출력 지원**: 설정에서 켜면 결과를 JSON으로 받아서 [[pi]]에 도구로 바로 연결할 수 있어요.
- **활발한 오픈소스**: 관리가 잘 되고 커뮤니티가 커요. 참고 자료도 많습니다.
- **모델도 로컬, 검색도 로컬**: 이 시리즈 철학과 정확히 맞아요.

## 약점
- **직접 구동해야 해요**: 보통 Docker로 한 번 설치하고 실행하는 수고가 들어요. (다음 설치 primitive에서 차근차근 다룹니다.)
- **upstream 차단 가능**: 너무 자주 부르면 뒤에 있는 검색엔진들이 일시적으로 막을 수 있어요.
- **본문 읽기는 따로**: SearXNG는 목록까지만 줍니다. 2단계 읽기는 별도 도구가 필요해요.

## 우리가 SearXNG를 고른 이유
무료 옵션을 쭉 비교([[웹검색엔진-무료옵션]])했을 때, **"공짜 + 범용 + 안정적 + 로컬"을 동시에 만족하는 건 사실상 SearXNG 하나**였어요.

- **YaCy**도 자체 호스팅이지만 인덱스가 들쭉날쭉하고 운영에 품이 많이 듭니다.
- **DuckDuckGo 스크래핑**은 공식이 아니라 언제 깨질지 몰라요.
- **상용 API**는 깔끔하지만 돈이 들고 검색어가 남의 서버로 나갑니다.

SearXNG는 이 셋의 단점을 한 번에 피해 가요. 메타 검색이라 결과도 좋고, JSON으로 깔끔하게 [[pi]]에 붙고, 무엇보다 **검색어 한 줄도 내 맥북 밖으로 안 나갑니다.** 로컬 LLM을 굴리는 이 시리즈의 취지에 가장 잘 맞아서, 우리는 SearXNG로 갑니다. 설치가 한 단계 더 드는 건 충분히 감수할 만한 값이에요.
